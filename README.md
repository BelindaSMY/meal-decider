# 饭什么

一个帮助“吃饭选择困难症”快速决定今天吃什么的响应式网页 MVP。

## 功能

- 按饭点、人数、预算、口味和忌口匹配
- 随机推荐与重新抽取
- 本地收藏推荐结果
- 一键搜索附近对应餐厅
- 多人偏好综合决策
- 一句话解释推荐原因
- 浏览器定位并通过 OpenStreetMap 查询附近真实餐厅
- 深色模式
- 手机与桌面端响应式布局

## 运行

直接打开 `index.html`，或者在目录中运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。
